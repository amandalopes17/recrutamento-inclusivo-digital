# 💼 Projeto: Recrutamento Inclusivo com Apoio Digital

## 📌 Descrição
Este projeto tem como objetivo propor melhorias no processo de recrutamento e seleção, com foco em inclusão e acessibilidade, utilizando ferramentas digitais simples.

A iniciativa foi desenvolvida com base na observação de práticas reais em ambiente hospitalar, buscando tornar o processo seletivo mais estruturado, eficiente e inclusivo para diferentes perfis de candidatos.

---

## 🎯 Objetivos
- Tornar o processo seletivo mais inclusivo
- Melhorar a experiência do candidato
- Padronizar etapas do recrutamento
- Utilizar ferramentas digitais para otimização do processo

---

## 🧠 Problema identificado
Durante a análise do processo de recrutamento, foram observados alguns pontos de melhoria:
- Falta de padronização nas etapas
- Linguagem pouco inclusiva nas descrições de vagas
- Ausência de coleta estruturada sobre necessidades específicas dos candidatos

---

## 💡 Solução proposta
Para resolver esses pontos, foram desenvolvidas as seguintes soluções:

### ✔ Modelo de vaga inclusiva
Criação de um padrão de descrição de vaga com linguagem mais acessível e inclusiva.

### ✔ Formulário digital
Utilização do Google Forms para coleta de dados de candidatos de forma mais organizada.

### ✔ Guia para recrutadores
Orientações com boas práticas para entrevistas mais inclusivas e conscientes.

### ✔ Padronização do processo
Definição de etapas claras: triagem → contato → entrevista → feedback.

---

## 🛠️ Ferramentas utilizadas
- Google Forms
- Google Docs
- Canva

---

## 🚀 Resultados esperados
- Melhor experiência para os candidatos
- Maior organização do processo seletivo
- Promoção da inclusão no ambiente organizacional
